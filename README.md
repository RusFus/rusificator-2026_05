# Руссификатор для Autodesk Fusion 360

**Версия: v06.26**

Русификатор интерфейса для Autodesk Fusion 360. Поддерживает две версии Fusion.

## Состав

- `RusFusion06.26.zip` — архив с русификатором
- `RusFus.exe` — установщик
- `RusFus.exe.config` — конфигурация
- `donate_qr.png` — QR-код для поддержки

## Установка

1. Скачайте `RusFusion06.26.zip`
2. Распакуйте архив
3. Запустите `RusFus.exe`
4. Нажмите «Установить»

## Поддерживаемые версии

- **Fusion 360 2703+** — новый набор ru-RU
- **Fusion 360 до 2703** — Legacy набор ru-RU
