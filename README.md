- v07.26 — для старых сборок Fusion

## Установка

1. Закройте Fusion 360.
2. Скачайте `RusFusion.zip` из раздела Releases и распакуйте архив.
3. Запустите `RusFus.exe` от имени администратора.
4. Нажмите «Установить русификатор» и дождитесь окончания установки.
