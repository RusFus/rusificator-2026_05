# RusFus — Русификатор для Autodesk Fusion 360

**Версия: v07.26**

Поддержка Fusion 2704.1.23 и новее.

## Установка

1. Скачайте [RusFusion07.26.zip](RusFusion07.26.zip)
2. Извлеките RusFus.exe
3. Запустите от имени администратора
4. Нажмите «Установить русификатор»

## Файлы локализации

Все файлы локализации встроены в exe, интернет не требуется.
